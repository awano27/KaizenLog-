### §C2 outcome_git.py の新設(fail-closed)

- 新規 `src/kaizenlog/outcome_git.py`。`collect_commit_stats(repo_paths, day, *, tz, timeout=5.0, max_repos=5) -> tuple[list[RepoCommitStat], int]`(第2要素は上限超過で省いたリポジトリ数)

- **受け入れ条件**: 一時ディレクトリに実gitリポジトリを作って境界時刻をまたぐコミット、binary、rename、mergeを置き、期間内の件数と±を確認する / 非リポジトリを渡すと結果から落ちる / timeout相当のモックで例外時に空になる / root/subdirの重複を1repoへ正規化できない場合は二重計測せず省略する。gitが無い環境ではテストをskipする。
