## 背景（第41弾レビューで確定した残件）

第41弾 §A1 の平文化は「📌 今日のアクション」区間のみに適用された。ノートの「🤖 AIコーチ」節の「### 明日の最小アクション」には台帳向け機械構文がそのまま残っている:

```
- [ ] KZN-…: <トリガー>→<行動>｜PASS: ai_retry_chains <= 0（リトライ連鎖数）｜FAIL: ai_retry_chains >= 1
```

読者向けには📌区間と同じ2行平文形式で表示し、機械構文は台帳と内部パイプラインだけに閉じ込める。

## §R1 AIコーチ節「明日の最小アクション」の平文化（本丸）

対象: `advisor.py:654` `render_reader_advice`（または cli.py:1295 直後の最終書き込み境界。**内部契約 Markdown の生成側は不変**）

- 読者向け再構成の出力に含まれる `### 明日の最小アクション` の各アクション行を、📌区間と同一の2行形式へ変換する:

  ```
  - [ ] KZN-20260801-001: <トリガー> → <行動>
      - 効果指標: リトライ連鎖数 を 0 以下 に
  ```

  - 変換には `memory.py` の `humanize_action_body` / `format_effect_metric_clause`（または `format_action_display_lines`）を**そのまま再利用**する。同等ロジックの重複実装は禁止。
  - KZN-ID が付与済みなら保持。未付与段階の行（pre-assign 経路がある場合）でも落ちずに動くこと。
  - 判定タグ（📌区間の「(8/1提案・判定 ⏳…)」）は advise 直後には存在しないため**不要**。効果指標行はラベル+閾値の和訳のみでよい。
  - `- なぜ効くと考えるか:` / `- 効かなかったと分かる条件:` のサブ行（mechanism/falsifier、advice_format.py:633-639）は**そのまま保持**する。
  - 機械構文でない自由文アクション（旧形式・`｜PASS:` を含まない行）は無変換で通す。
- 台帳（Kaizen Memory）へ保存される action 文字列・内部契約 Markdown・`validate_advice`・`assign_action_ids`・`_assert_render_shape` は**一切変更しない**。
- **受け入れ条件**: フェイク LLM 応答を使った統合テストで、ノートに書き込まれる ADVICE 区間に `｜PASS:` `｜FAIL:` および生メトリック名（ラベルが取れる場合）が出現しない。台帳エントリの action は機械構文のまま。KZN-ID・チェックボックス・サブ行は保持。
