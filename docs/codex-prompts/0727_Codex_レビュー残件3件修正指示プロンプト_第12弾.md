## §R2 [Low] 既 done エントリへの再 `done` で done_date が上書きされる

## §R3 [Low] 非 Windows で notify_failed が偽陽性記録される

`src/kaizenlog/notify.py:26-27`、`src/kaizenlog/cli.py:143-145`

**問題**: `notify()` は非 Windows で常に False を返すため、非 Windows 実行(CI・WSL等)では通知のたびに `notify_failed` が runlog に記録される。旧仕様は no-op だった。

1. 非 Windows は「送出を試みていない」ので失敗と区別する: 戻り値を3値にするか(`sent / failed / skipped`)、呼び出し元で `sys.platform` により記録をスキップする。いずれでも可、ただし **Windows での失敗検知(§M5)の挙動は変えない**

テスト: 非 Windows 相当(platform モック)で notify_failed が記録されない / Windows の失敗時は従来どおり記録される。
