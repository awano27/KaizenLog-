## §F1 判定書き戻しの空行増殖バグ（第1弾 A1-3 起因）

`src/kaizenlog/verdict.py:196-202` `apply_verdicts_to_advice_note`

- **問題**: `body.splitlines()` は先頭改行を空文字列要素として保持するため、`new_body = "\n" + "\n".join(new_lines) + "\n"` が改行を二重付与し、判定 suffix が書き込まれる（＝値が変わる）たびに ADVICE 区間先頭へ空行が1行ずつ蓄積する。`prefix_nl`（199行）は未使用のデッドコードで、三項演算子の両分岐が同値
- **修正**: `prefix_nl` を削除し、`new_body = "\n".join(new_lines)` を基準に「先頭と末尾にちょうど1つの改行」を保証する正規化にする（先頭が `\n` で始まらなければ付与、末尾も同様）
- **テスト**: 判定書き込み→実測値変更→再書き込みを3回繰り返しても、ADVICE 区間内の行数（空行数）が不変であること

## §F2 意味ガードの JSON 層迂回とエラー誤分類（第4弾 L1 起因）

`src/kaizenlog/advice_format.py:141-158`（`_join_text_fields`）、`advice_format.py:322-326`（レンダラのインバリアント）、`src/kaizenlog/cli.py:431`

- **問題**: `_join_text_fields` は fact_ids をテキストから除外するため、`_semantic_contract_errors` のうち文中の `[F4]` / `[F1]` 等を前提とするガード（画面ブロック→会話数変換、カテゴリ変更→通知・割り込み変換）が `validate_advice` 経路で発火しない。違反はレンダリング後のインバリアントで初めて検出されるが、そこでは `AdvisorError("renderer bug: ...")` として送出され、(a) LLM への修復リトライも (b) `cmd_advise` の `except AdviceContractError`（L2 縮退保存）も通らない。LLM のコンテンツ違反が「レンダラのバグ」に誤分類される
- **修正（2段）**:
  1. `validate_advice` に per-item の文脈ガードを追加する。plan_review を除く各 item（proposals / actions / ai_review）について:
     - `"F4" ∈ fact_ids` かつ `"F5" ∉ fact_ids` かつテキストに `会話|セッション|往復` が現れる（不確実性言語・計測指示文の除外は既存の `_has_uncertainty_language` / `is_measurement_instruction` 相当を再利用）→ 違反「AI関連画面ブロック数を会話数・セッション数・往復数へ変換しています」
     - `fact_ids ∩ {F1, F8, F9} ≠ ∅` かつ `"F5" ∉ fact_ids` かつテキストに `通知|割り込み|中断|(生産性|集中力).{0,6}(低下|下が|悪化)` → 違反「カテゴリ変更回数を通知・割り込み・生産性低下へ変換しています」
     - 必要な判定関数は advisor.py から advice_format.py へ移設または import（循環 import に注意。第1弾で使った遅延 import 方式でよい）
  2. レンダラのインバリアントを分類する: `contract_errs = advice_contract_errors(rendered, evidence)` のうち `_semantic_contract_errors(rendered, evidence)` に含まれるものだけなら `AdviceContractError` を送出（→ 呼び出し元で修復・L2 縮退の既存経路に乗る）。構造系エラーが1つでも含まれる場合のみ従来どおり `AdvisorError("renderer bug: ...")`
     - `generate_advice` 側で、レンダリング時の `AdviceContractError` も修復1回の対象になることを確認（validate 合格→render で意味違反検出のケース。修復プロンプトには検出された違反を渡す）
- **テスト**: (a) F4 のみ引用した ai_review.text「セッションが細切れになっている」→ `validate_advice` が違反を返す / (b) インバariントの分類: 意味violationのみ→`AdviceContractError`、構造破壊（見出し欠落等を人工的に注入）→`AdvisorError` / (c) 意味違反が修復プロンプト経由で直る統合テスト
