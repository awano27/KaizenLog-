# Codex 指示プロンプト アーカイブ

このディレクトリは KaizenLog 改善ループで使った **Codex 向け実装指示書** の保管場所です。

- ファイル名の `第N弾` が適用順の目安（0725 → 0729 の日付プレフィックス付き）。
- 各指示は「ワーキングツリーに実装を残し、**git commit / push はユーザー判断**」を前提にしている。
- レビュー駆動: 実装後に指摘を次弾プロンプトへ落とし、小さく直す。
- 共通禁止: 実 LLM/ネットワークをテストから呼ばない、マーカー外ノートを触らない、タスク登録を自動化しない。
- 製品コードの履歴は git コミットを正とし、ここは設計意図・受け入れ条件の一次メモとして参照する。

新規の指示書を足す場合も、ルート直下ではなくこのフォルダへ置く。
